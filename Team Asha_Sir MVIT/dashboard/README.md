# Clinician dashboard

`index.html` is a committed, self-contained offline dashboard: open it directly
in a browser with `file://`. It uses no CDN, framework, remote fonts, or
network request.

## Rebuild

From `Team Asha_Sir MVIT/`:

```bash
python3 scripts/make_synthetic_patient.py
python3 scripts/build_dashboard.py
```

`twin_data.json` is the canonical real-cohort payload generated by the Kaggle
notebook. `_template.html` contains the dashboard UI. The build embeds that
payload and `synthetic_patient.json` into `index.html`, so `fetch()` is never
needed under `file://`.

The synthetic patient is visibly labelled SYNTHETIC and is excluded from every
cohort statistic; `build_dashboard.py` asserts that it cannot enter the burden
analysis.
